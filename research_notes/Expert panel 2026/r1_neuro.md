# Round 1 — Neuroscientist

## 1. What neuroscience predicts in the results
- **MovieLens = Tse et al. 2007.** Rats learned new flavour–place pairs in one trial (consolidated ~48 h) only after weeks building a consistent map; inconsistent map → no fast learning. McClelland 2013, SLIMM (van Kesteren 2012): schema-consistent info absorbed fast via mPFC; inconsistent slowly via hippocampus. CF = cortex learned from everyone; person vector = fast fill-in. LLM film knowledge isn't a taste schema. Predicted, not surprising.
- **Notebook vs hippocampal indexing (Teyler & DiScenna).** Hippocampal input comes from entorhinal cortex at top of hierarchy; "concept cells" fire for a person's photo, written and spoken name alike (Quiroga 2005). Key = concept, not string. Name identity surviving only in early layers = the LLM has no entorhinal-like stage; deep states carry the next word. So lexical keys miss aliases and collide on substrings. Dentate-gyrus pattern separation would sharpen "Francis" vs "Francis II" but separates whatever it's fed. Engineering equivalent of entorhinal cortex: an entity linker (KBLaM, Entities as Experts).
- **Composition (9.4%; CF 0.40 vs T 0.82).** Brains don't silently compose two fresh episodic facts either. Two routes: (1) deliberate step-by-step retrieval — one recall's answer cues the next (REMERGE, Kumaran & McClelland 2012); (2) integrative encoding — learning B→C reactivates overlapping A→B and binds them (Zeithamova & Preston 2010; Schlichting 2015, blocked order favours integration). Fresh fact composes easily with a consolidated one. Balesni v4 (Nov 2025): separately learned facts compose without CoT if in the same training document or if one came from pretraining. T-vs-CF gap fits.
  - CF chain failure looks like **encoding specificity (Tulving)**: model words its sub-question differently from the cue the fact was written under. Cheap fix: also key each fact under the model's own wordings of the sub-question (doc2query-style). Do first.
  - The 19.5% old answers = **proactive interference.** Reconsolidation (Nader 2000, Sevenster 2013): recalled memory meeting prediction error becomes unstable and is rewritten. The memory adds the new fact but never weakens the old route.
- **Paste 1,000 → 13%; paste one → 92%.** Working memory ~4 items; hippocampus delivers the few that matter precisely.
- **Perseveration** = prefrontal sign (Wisconsin Card Sorting). Brains separate expected uncertainty (noise; ACh) from unexpected uncertainty (model wrong; NE). NE burst → network reset (Yu & Dayan 2005; Bouret & Sara 2005). Agent has one channel and patches everything.
- **Hebbian counting on CIFAR**: without competition (lateral inhibition, normalisation) converges to principal components. Drop it.
- **Commutativity**: integration is an interaction — what's written for B→C must depend on A→B. A sum of independent per-fact terms is a filing cabinet by design. Keep order-free updates for the journal and coordinates inside a fixed schema; get integration from a joint offline pass (sleep) that adds cross terms. = CLS in one line.
- **Skills**: no one-shot skill learning in brains. Instructions run slowly from working memory, then compiled by practice (dopamine prediction errors). AI version exists: System-2 distillation (Yu et al. 2024).

## 2. Proposals
**P1. Overlap-targeted sleep replay — integrate or only cache?** Sleep co-replays memories sharing elements; shared elements strengthen into a schema (Lewis & Durrant 2011). Each night find stored facts sharing an entity (A→B with B→C, or new + pretrained); write short passages mentioning both, mixed with model-generated text on old knowledge; train into weights. Prior art: Balesni v4; EntiGraph (2409.07431); Synthesize-on-Graph (2505.00979); PropMEND, SEAL; Grokked Transformers (no OOD composition). **Open question:** after co-replaying A→B→C, does a separately learned D→B compose with B→C? Yes → sleep built an integrated node (schema). No → only caches composites (cost grows with chains). Experiment: Qwen3.5-4B LoRA, 1,000 fictional facts, 300 bridge entities, three arms equal tokens: separate docs; co-replay; co-replay with B→C in bridged form. Score no-CoT two-hop by logprob on co-replayed and transfer (D→B→C) chains. Gate: co-replayed beats baseline. Pass: transfer ≥ 3× baseline and ≥ 30% of co-replayed accuracy, unrelated QA within 1 pt. Stop: transfer ≤ 1.5× baseline → use CoT + precise retrieval, co-replay as cache for frequent chains. Cost 3–6 A100 h, ~$5 API or none.

**P2. Surprise-gated reset for the scientist agent.** Code tracks current rule's violation rate vs estimated noise. Below threshold → patch; above → fresh context, old rule shown only as "excluded", propose K rules from a different family. Prior art: Qiu et al. ICLR 2024; MATSIR (ACL Findings 2026) backtracking; LLM reversal rigidity (2604.04182). No test found of surprise-gated restart vs patching at equal compute. Experiment: existing harness + mid-stream rule switches + noisy labels; arms always-patch / always-restart / gated, equal tokens. Pass: gated recovers in ≤ half the trials patching needs after a switch, and beats always-restart by ≥ 5 pts on noisy unchanged-rule tasks. Stop: always-restart ≥ gated everywhere (= best-of-N with verification, known). Cost 2–4 H100 h.

**P3. Counting inside a learned schema (phone architecture).** Learn 16–64-dim user space from many people (backprop, slow); each person keeps only order-free sufficient statistics (XᵀX, Xᵀy): exact deletion, KB per person. LLM supplies item features where population has no data. Prior art heavy: VPL, PAL, LoRe, LLM cold-start. Engineering, not breakthrough. Test: MovieLens items with ≤ 5 ratings; pass ≥ +0.03 AUC over both CF and popularity.

## 3. Where the analogy misleads
- One-exposure learning mostly a myth: fast mapping is mainly referent selection; little retained after one exposure without repetition and sleep (Horst & Samuelson 2008); adult fast mapping into cortex (Sharon 2011) failed to replicate (Cooper 2019).
- Brain memory is reconstructive, order-dependent, undeletable. Exactness, deletion, accountability are your strengths; don't trade them for plausibility.
- Silent composition of fresh facts is beyond brains. Brain-like bar: precise cued retrieval during deliberate reasoning now; silent use only after consolidation.
- The "cortex" isn't the bottleneck (pretraining provides one). Missing: concept-level cues and a consolidation policy.
- Neuromodulator stories are cheap; use only where the quantity is computable (surprise from logprobs, violation counts).
